# `sh`-ish 🤷‍♂️

This is an umbrella package that intends to make Cargo scripts slightly more ergonomic.

## Components

- `shish-lib` - the library that re-exports common utilities.
- `shish` - a small command-line tool that that automates boilerplate.

## What are Cargo scripts?

See [RFC#3502](https://rust-lang.github.io/rfcs/3502-cargo-script.html)
